## [0.1.0]
### Added
- Initial release of `n8n-nodes-falcon` community node package.
- Core integration architecture for CrowdStrike Falcon API using official `crowdstrike-falcon` SDK.
- OAuth2 client credentials authentication mechanism (`CrowdStrikeFalconApi.credentials.ts`) with automatic token renewal.
- Main node definition (`CrowdStrikeFalcon.node.ts`), central execution router (`router.ts`), and helper utilities (`GenericFunctions.ts`).
